## Sobre o Projeto
Este projeto é um simulador simples de escalonamento de processos. O objetivo é demonstrar como quatro regras diferentes organizam o uso da CPU numa fila de atendimento. Os algoritmos implementados são:
- **FCFS** (First-Come, First-Served)
- **SJF** (Shortest Job First)
- **Prioridade**
- **Round Robin** (com quantum de 2)

## Linguagem Utilizada
O projeto foi desenvolvido em **Python**. A simulação corre inteiramente no terminal e os dados dos três cenários exigidos estão codificados diretamente no script, não sendo necessário utilizar bases de dados ou leitura de ficheiros externos.
